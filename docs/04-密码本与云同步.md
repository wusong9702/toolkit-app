## 二、功能清单（已实现）

### 1. 主密码锁
- 首次进入需**创建主密码**（≥8 位）；锁定后需解锁
- **忘记主密码 = 数据无法恢复**（端到端加密的设计本质）

### 2. 搜索（主页顶部）
- 输入即搜，匹配**名称 / 密码 / 备注 / 标签 / 分组**（不分大小写）
- 搜索结果卡片：点名称区复制名称，点密码行复制密码

### 3. 收藏
- 条目星标（主页 + 全部页均可切换），收藏项固定显示在主页「我的收藏」区
- 收藏区：点名称复制名称、点密码区复制密码、再点星标取消收藏

### 4. 分组 / 标签
- 每条密码 1 个**分组** + 任意多个**标签**，全部自定义
- 主页分组宫格显示每个分组的条目数，点击直达筛选列表

### 5. 自定义名称 + 密码
- 名称密码完全自定义；支持**一键随机生成** 16 位强密码
- 编辑页可切换明文/掩码查看

### 6. 点击复制
- 所有列表**点名称区复制名称、点密码行复制密码**（掩码显示，复制真实值）
- 双级降级：navigator.clipboard → execCommand 兜底（iframe/非 https 环境也能用）

### 7. 手动排序
- 全部页每条有「置顶 / 上移 / 下移」，排序持久化

### 8. 失效时间
- 每条可设「永不过期 / 指定日期时间」
- 到期后条目**置灰 + 「已失效」红标**，仍可编辑重新生效

### 9. 本地加密存储
- **PBKDF2(主密码, 随机盐, 15万次迭代) → AES-256-GCM** 加密写入 localStorage
- 明文永不落盘（仅存在于解锁后内存）

### 10. WebDAV 云同步（端到端加密）
- 设置页填 地址/账号/应用密码/目录名
- **测试连通**：三步验证（PROPFIND 认证 → 目录可写 → 探测云端备份），结果直接显示；连通成功自动保存配置
- **每次编辑后自动推送**（防抖 300ms）
- **删除云端数据**：三选一动作面板 —— 仅删云端（本地保留）/ 云端+本地全部删除（二次确认）/ 取消
- 支持：坚果云、Nextcloud、ownCloud、自建 NAS
- ⚠️ **CORS 限制**：坚果云不发跨域头，**浏览器网页版直连会被拦**；打包成 App（Capacitor 原生壳）后无此限制

## 三、数据结构

```ts
interface VaultEntry {
  id: string
  name: string        // 名称（自定义）
  password: string    // 密码（自定义 / 随机生成）
  group: string       // 分组（自定义）
  tags: string[]      // 标签（自定义，多个）
  note: string        // 备注
  expiresAt: number   // 失效时间戳（ms），0 = 永不过期
  favorite: boolean   // 是否收藏（主页「我的收藏」区）
  sort: number        // 排序权重
  createdAt: number
  updatedAt: number
}
```

| -- | -- | -- |

| 7 | 主页点分组宫格 | 进入全部页并定位到该分组 |
| 8 | 点收藏区/列表的密码行 | Toast「已复制密码」，剪贴板是真实密码 |
