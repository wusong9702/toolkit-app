## 二、推荐：本机启动（Windows）

### 第 1 步：打开终端

按 `Win` 键，输入 `powershell`，回车。

### 第 2 步：进入项目目录

```powershell
cd C:\Users\admin\WorkBuddy\2026-08-31-08-54-12\app
```

> 如果你把项目挪到了别的地方，把上面路径换成实际位置。
> 不确定在哪？在文件管理器里找到 `app` 文件夹，地址栏复制路径。

### 第 3 步：安装依赖（**只在第一次需要**）

```powershell
npm install
```

看到进度条走完、没有红色 `ERR` 就成了。**这一步要联网**，通常 1-3 分钟。

**如果卡住或报网络超时**（国内常见），改用国内镜像重试：

```powershell
npm install --registry=https://registry.npmmirror.com --fetch-timeout=300000 --fetch-retries=8
```

### 第 4 步：启动

```powershell
npm run dev
```

终端会显示类似这样：

```
➜  Local:   http://localhost:5173/
➜  Network: http://192.168.1.23:5173/
```

### 第 5 步：打开浏览器

- **电脑上**：浏览器打开 `http://localhost:5173/`
- **手机上**（推荐，能测真实触感）：手机连同一个 WiFi，浏览器打开终端显示的 `Network:` 那行地址

> 想看手机上的效果更方便，可以用浏览器扫码：`npm run dev` 后终端有时会显示二维码。
> 没有的话就手输地址。

### 停止服务

在终端按 `Ctrl + C`，然后输入 `Y` 回车。

## 三、换电脑怎么拿代码

### 方法 A：用 SSH（之前配过密钥的那台才能用）

```powershell
git clone git@github.com:wusong9702/toolkit-app.git
cd toolkit-app\app
npm install
npm run dev
```

**新电脑上没配过 SSH 会报 `Permission denied (publickey)`**，两个办法：

- 简单办法：直接用方法 B（HTTPS）
- 一劳永逸：在新电脑生成密钥，把公钥加到 GitHub
  （`github.com/settings/keys` → New SSH key）

### 方法 B：用 HTTPS（任何电脑都能用）

```powershell
git clone https://github.com/wusong9702/toolkit-app.git
cd toolkit-app\app
npm install
npm run dev
```

弹窗要你登录时：

- **用户名**：`wusong9702`
- **密码**：**不能填登录密码**！要去 GitHub 生成 Personal Access Token
  （`github.com/settings/tokens` → Generate new token (classic) → 勾选 `repo` → 生成后复制，粘到密码框）

代码推到 `main` 分支后，GitHub 会自动构建部署（约 1-3 分钟）。

访问地址：

```
https://wusong9702.github.io/toolkit-app/
```

**如果打不开**（404 或一直转圈）：

1. 打开 `github.com/wusong9702/toolkit-app/actions` 看部署任务是否成功（绿色勾 = 成功）

## 六、常见报错怎么办

| 报错 | 原因 | 解决 |
| -- | -- | -- |
| `'vite' 不是内部或外部命令` | 依赖没装全 | 重跑第 3 步的 `npm install` |
| `Port 5173 is in use` | 端口被占 | `npm run dev -- --port 5174` |
| `ETIMEDOUT` / `network timeout` | 网络不稳 | 换国内镜像重试（第 3 步第二条命令） |
| 打开是白屏 | 资源没加载 | 按 `F12` 看 Console 红色报错，截图发给我 |
| 改了代码页面没变 | 浏览器缓存 | `Ctrl + Shift + R` 强制刷新 |
| 手机连不上局域网地址 | 防火墙拦了 | 关掉电脑防火墙再试，或改用 Pages 地址 |

## 七、几个必须知道的提醒

1. **主密码忘了 = 数据救不回来**。这是端到端加密的代价，不是 bug。测试时先用一个你肯定记得住的。
2. **数据存在浏览器本地**（localStorage），换浏览器、清缓存、用无痕模式都会看不到。**正式使用前务必配好 WebDAV 云同步**。
3. **坚果云在网页版会被浏览器跨域拦截**，测试连通会失败——这不是配置错。要用坚果云得打包成 App；Nextcloud / 自建 NAS 没这问题。
4. **每次改完代码想同步到 GitHub**（在你电脑上）：
   ```powershell
   git add -A
   git commit -m "说明改了什么"
   git push
   ```
   GitHub 会自动重新部署 Pages（约 1-3 分钟）。
